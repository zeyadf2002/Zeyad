# نقل: تطبيق يجمع شركات نقل السيارات

تطبيق جوال (Flutter) يطلب فيه العميل نقل سيارته، فتصله عروض أسعار من عدة شركات، يقارن بينها ويحجز ويتابع حالة النقل. وفيه وضع خاص بالشركات لاستقبال الطلبات وإرسال العروض.

## الشاشات
1. الرئيسية: اختيار المدن وعرض الشركات الموثوقة
2. طلب نقل: السيارة، نوع الناقلة، تاريخ الاستلام
3. مقارنة العروض: ترتيب حسب الأرخص أو الأسرع أو التقييم، ثم الحجز
4. تتبع الطلب: من تأكيد الحجز حتى التسليم
5. ملف الشركة ودليل الشركات
6. وضع الشركة: الطلبات الجديدة، إرسال عرض سعر، العمولة المستحقة

## الحالة الحالية
البيانات حاليًا في الذاكرة (`lib/data/app_state.dart`) لأغراض التجربة. الخطوة التالية ربطها بقاعدة بيانات (Firebase) وتسجيل الدخول برقم الجوال.

خطة النسخة الأولى: [docs/mvp-plan.md](docs/mvp-plan.md)
